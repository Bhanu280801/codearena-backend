# CodeArena Frontend

The Next-Generation Coding Platform frontend, built with a modern developer-first architecture.

## Folder Structure

\`\`\`
codearena-frontend/
├── public/                 # Static assets
├── src/
│   ├── components/         # Reusable UI elements
│   │   ├── layout/         # RootLayout, navigation, etc.
│   │   └── ui/             # shadcn/ui generic components (buttons, inputs)
│   ├── features/           # Feature-driven modules (Auth, Workspace, Dashboard)
│   │   ├── auth/           # Login/Register pages & hooks
│   │   └── workspace/      # Editor, Problems, Console panels
│   ├── lib/                # Utility functions (cn, axios config)
│   ├── router/             # React Router definitions
│   ├── store/              # Zustand global state
│   ├── App.tsx             # Root component
│   └── index.css           # Global design system & Tailwind layers
├── .env                    # Environment variables
├── components.json         # shadcn/ui configuration
├── tailwind.config.js      # Theme, colors, animations
└── vite.config.ts          # Vite build config with path aliases
\`\`\`

## Component Architecture

This project uses a **Feature-Sliced Design** approach:
1. **\`src/features/*\`**: Contains domain-specific logic, pages, and components that shouldn't be reused outside their domain (e.g., \`EditorPanel\`).
2. **\`src/components/ui/*\`**: Contains generic, highly reusable design-system components generated by \`shadcn/ui\`.

## State Management

We use a strictly divided state management approach to ensure performance:
1. **Zustand (`src/store/*`)**: Used exclusively for global UI state (Theme, Auth State, Command Palette visibility, Layout preferences). It uses `localStorage` middleware to persist auth sessions.
2. **TanStack React Query**: (To be fully integrated with backend) Used for all server-state caching, data fetching, and polling (e.g., getting problem lists, checking submission status).

## Environment Variables

Create a `.env` file in the root directory:
\`\`\`env
# The base URL of the codearena-backend API
VITE_API_URL=http://localhost:5000/api
\`\`\`

## API Integration Guide

All API requests are routed through a centralized Axios instance located in `src/lib/axios.ts`.
- **Interceptors**: Pre-configured to automatically handle JWT tokens and catch `401 Unauthorized` responses globally for refresh-token flows.
- **Usage**: To fetch data, import the `api` instance and use it inside a React Query hook.
\`\`\`typescript
import { api } from "@/lib/axios"
import { useQuery } from "@tanstack/react-query"

// Inside a component:
const { data } = useQuery({
  queryKey: ["problems"],
  queryFn: () => api.get("/problems").then(res => res.data)
})
\`\`\`

## Setup Instructions

1. Ensure Node.js 18+ is installed.
2. Clone/navigate to the `codearena-frontend` directory.
3. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
4. Run the development server:
   \`\`\`bash
   npm run dev
   \`\`\`

## Deployment Instructions

1. **Build for Production**:
   \`\`\`bash
   npm run build
   \`\`\`
   This will generate a highly optimized `dist/` folder using Vite.
2. **Hosting**: Deploy the `dist/` folder to Vercel, Netlify, or an Nginx server. If using Vercel, simply link the repository and use the "Vite" preset.
3. Ensure you set the `VITE_API_URL` environment variable in your hosting provider's dashboard to point to your live production backend URL.
